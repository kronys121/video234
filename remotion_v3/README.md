# TLOU2 на Remotion — монтаж v3 («как в референсе»)

Первые 31 секунда ролика про The Last of Us Part 2 в новом монтаже, снятом покадрово с референса.

## Как запустить

```
npm install
npm run studio     # предпросмотр с ползунком
npm run render     # готовое видео: out/tlou2_v3.mp4 (8 потоков)
```

## Приёмы монтажа

- **Один холст на группу сцен.** Соседние сцены стоят рядом, камера плавно переезжает между ними за 1 секунду (без рывка и размытия), старая сцена остаётся краем в кадре.
- **Растворение** между группами сцен: 0,45 секунды.
- **Фокус:** новый объект влетает снизу поверх сцены, а сцена под ним размывается и темнеет.
- **Влёт объектов** снизу с доворотом, без отскока; после этого объект слегка «дышит».
- **Камера** всё время медленно наезжает и чуть покачивается в 3D.
- **Подписи** небольшие, печатаются по буквам, последняя буква мягко проявляется.
- Эмодзи — шрифт Noto Color Emoji, лежит в проекте (`public/fonts`), поэтому одинаковы на любом компьютере.

Все тайминги собраны в `src/engine.ts` (объект `T`), сцены — в `src/Video.tsx` (массив `GROUPS`).
