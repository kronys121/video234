# Crysis на консолях — 11 шортов (Remotion, 1080×1920, 60 к/с)

1. «А Crysis потянет?» · 2. С чего всё началось: Far Cry · 3. Crysis 2007: джунгли и нанокостюм · 4. Игру не тянуло ничего ·
5. 512 МБ на всё: Xbox 360 и PS3 · 6. CryEngine 3 и Нью-Йорк · 7. Crysis на консолях: чем заплатили · 8. Дальность и сглаживание ·
9. Вырезанный уровень «Восхождение» · 10. Crysis на Switch · 11. Can it run Crysis? — теперь это пресет

Анимации из полного ролика; окно монтажа подобрано по каждой сцене — всё помещается в 9:16.
Субтитры — текст сценария, выровненный по озвучке. Снизу «ПОЛНОЕ ВИДЕО НА YOUTUBE-КАНАЛЕ KRONYS», в конце «ПРОДОЛЖЕНИЕ НА YOUTUBE-КАНАЛЕ KRONYS».

## Как запустить (Windows)
1. Node.js 18 или новее: https://nodejs.org
2. **render.bat** — рендерит все 11 шортов в `out\`. Один шорт: `npm run render1` … `render11`. **studio.bat** — предпросмотр.
