# Змейка — видео 1920×1080

Видео (11:29, 1920×1080, H.264, ~4,5 Мбит/с, 401 МБ) разрезано на 4 части,
потому что GitHub не принимает файлы больше 100 МБ. Части — это куски одного файла,
по отдельности они не проигрываются. После сборки получается точная копия исходного `video.mp4`.

## Как собрать

**Windows:** скачай все 4 файла `video.mp4.001` … `video.mp4.004` и `sobrat.bat` в одну папку,
запусти `sobrat.bat` двойным щелчком — рядом появится `video.mp4`.

Вручную (командная строка в этой папке):

    copy /b video.mp4.001 + video.mp4.002 + video.mp4.003 + video.mp4.004 video.mp4

Или в 7-Zip: правой кнопкой по `video.mp4.001` → 7-Zip → «Объединить файлы».

**macOS / Linux:**

    cat video.mp4.001 video.mp4.002 video.mp4.003 video.mp4.004 > video.mp4

Проверка (SHA-256 собранного файла):
`3a353c3461fea90780bd22bf0fd5d4b8e85230998b59d70cbb422e2801b3e7b8`
