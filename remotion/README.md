# TLOU2: первая минута на Remotion

Первая минута ролика про The Last of Us Part 2: та же озвучка и сцены, плюс новые возможности Remotion.

## Как запустить

Нужен Node.js 18 или новее: https://nodejs.org

```
npm install
npm run studio     # предпросмотр с таймлайном в браузере
npm run render     # готовое видео: out/tlou2_minute.mp4 (8 потоков)
```

При первом запуске Remotion сам скачает нужный браузер, поэтому нужен интернет.

## Что нового

- **Правки в Studio.** Каждая надпись, клип, картинка и засвет — отдельный элемент на таймлайне. Его можно выделить, сдвинуть по времени, поменять текст, положение (X, Y) и наклон. Studio сама записывает изменения в код.
- **Настоящее размытие в движении** (`CameraMotionBlur`): каждый кадр собирается из 8 промежуточных положений. Режим и число снимков задаются в начале `src/Minute.tsx`: `MOTION_BLUR` (`camera`, `html` или `simple`) и `MOTION_BLUR_SAMPLES`.
- **Цветокоррекция:** холоднее и темнее фоны, чуть сочнее клипы.
- **Плёночное зерно** поверх всего кадра.
- Все эффекты сделаны на CSS и SVG, без WebGL: так рендер не падает из-за лимита WebGL-контекстов в Chrome.
- **Засветы** на трёх переходах (дорожка «Засветы»).
- **Пометки от руки:** обвод «7 ЛЕТ» и «2020», подчёркивания, маркер на «А ЧТО, ЕСЛИ…», рамка вокруг «ПОЛНАЯ СВОБОДА».
- **Звуки переходов** («вжух») на каждой смене сцены, отдельная дорожка.
- **Клипы как mp4**, а не тысячи картинок.

## Что где

- `src/Minute.tsx`: сцены, фоны, засветы, зерно, звук.
- `src/elements.tsx`: элементы (клип, обложка, предмет, подпись, плашка, цифра, эмодзи, стрелка) и пометки от руки.
- `src/engine.ts`: появление элементов и камера.
- `public/`: клипы, картинки, шрифты, озвучка, звук перехода.
