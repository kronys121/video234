# GTA 6 — шорт для TikTok / Shorts / Reels (Remotion, 1080×1920, 60 к/с, 1:03)

Те же анимации, что в полном ролике (вырезки, иконки, надписи, цифры), в вертикальном формате:
монтаж по центру с мягкими краями, за ним размытая копия кадра, сверху крючок «GTA 6 НЕ ДОЛЖНА БЫЛА РАБОТАТЬ НА PS5»,
снизу субтитры по словам (текущее слово жёлтое), в конце «ПРОДОЛЖЕНИЕ НА КАНАЛЕ @kronyscs».

Озвучка: 0:00–0:21 и 4:03–4:41 полного ролика. Музыка: Electro Cabello.

## Как запустить (Windows)

1. Установи Node.js 18 или новее: https://nodejs.org
2. Дважды кликни **render.bat** — поставит зависимости (один раз), нарежет клипы в кадры и отрендерит видео в `out\gta6_short_tiktok.mp4`.
   **studio.bat** — предпросмотр с ползунком.

Если компьютер слабый — уменьши `--concurrency=6` в `package.json`.

## Что где

- `src/Short.tsx` — вся вёрстка шорта: крючок, субтитры, метка канала, финальная карточка, раскладка 9:16.
- `src/short_data.json` — тайминги кусков озвучки и слов для субтитров (можно поправить текст слова).
- `public/site/gta6/` — движок монтажа из полного ролика.
- `public/media/short_audio.m4a` — звук.
