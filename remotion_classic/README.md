# TLOU2 на Remotion: первая минута

Первая минута ролика про The Last of Us Part 2 в стиле основного ролика: та же озвучка, сцены и анимации (движок v2 один в один). Без дополнительных эффектов.

## Как запустить

Нужен Node.js 18 или новее: https://nodejs.org

```
npm install
npm run studio     # предпросмотр с ползунком в браузере
npm run render     # готовое видео: out/tlou2_minute.mp4 (8 потоков)
```

## Что где

- `src/Pilot.tsx`: сцены. Элементы появляются по словам озвучки (`w('слово')`), правило «держать на экране минимум 2 секунды» встроено.
- `src/components.tsx`: карточки, клипы, предметы, печатающиеся подписи, плашки.
- `src/engine.ts`: появление элементов, камера, поиск слов в `src/words.json`.
- `public/`: кадры клипов (jpg, 30 к/с), картинки, шрифты, озвучка.
