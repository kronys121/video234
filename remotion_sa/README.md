# GTA San Andreas — полный ролик с рекламой ggsel (рендер через Remotion)

Ролик GTA San Andreas (7:55) с рекламой ggsel в 2:53. Итог — 8:37.
Сцены рисует тот же движок, что и в прошлых роликах; Remotion снимает кадры и собирает видео со звуком.

## Как запустить

Нужен Node.js 18 или новее: https://nodejs.org

```
npm install
npm run render     # готовое видео: out/gta_sa_final.mp4 (8 потоков)
npm run studio     # предпросмотр с ползунком
```

При первом запуске клипы из `clips_src/` нарезаются в кадры (папка `public/site/gta_sa/clips`) — пару минут, дальше пропускается.

## Что где

- `src/Full.tsx` — склейка: ролик до 2:53, реклама (твой файл), ролик дальше; голос без обрезки.
- `public/site/gta_sa/` — страница движка со всеми сценами.
- `public/media/` — озвучка и отрезок рекламы.
- Эмодзи — шрифт Noto Color Emoji внутри проекта.
