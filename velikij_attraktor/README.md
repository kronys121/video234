# Великий аттрактор — видео 1920×1080

Видео (21:47, 1920×1080, H.264, 24 к/с, 559 МБ, только голос, без субтитров) разрезано на 6 частей,
потому что GitHub не принимает файлы больше 100 МБ. Части — это куски одного файла,
по отдельности они не проигрываются. После сборки получается точная копия исходного `video.mp4`.

## Как собрать

**Windows:** скачай все 6 файлов `video.mp4.001` … `video.mp4.006` и `sobrat.bat` в одну папку,
запусти `sobrat.bat` двойным щелчком — рядом появится `video.mp4`.

Вручную (командная строка в этой папке):

    copy /b video.mp4.001 + video.mp4.002 + video.mp4.003 + video.mp4.004 + video.mp4.005 + video.mp4.006 video.mp4

Или в 7-Zip: правой кнопкой по `video.mp4.001` → 7-Zip → «Объединить файлы».

**macOS / Linux:**

    cat video.mp4.001 video.mp4.002 video.mp4.003 video.mp4.004 video.mp4.005 video.mp4.006 > video.mp4
