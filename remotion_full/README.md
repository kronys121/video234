# TLOU2 — полный ролик с рекламой ggsel (рендер через Remotion)

Весь ролик The Last of Us Part 2 (8:39) с рекламой ggsel в 3:52. Итог — 9:17.
Сцены рисует исходный движок (ровно как в прошлых роликах), Remotion снимает кадры и собирает видео со звуком.

## Как запустить

Нужен Node.js 18 или новее: https://nodejs.org

```
npm install
npm run render     # готовое видео: out/tlou2_final.mp4 (8 потоков)
npm run studio     # предпросмотр с ползунком
```

При первом запуске клипы из `clips_src/` нарезаются в кадры (папка `public/site/tlou2/clips`, около 650 МБ) — это пару минут, дальше пропускается.

## Что где

- `src/Full.tsx` — склейка: ролик до 3:52, реклама, ролик дальше; звук голоса без обрезки.
- `public/site/tlou2/` — страница движка со всеми сценами.
- `public/media/` — озвучка и готовый отрезок рекламы.
- Эмодзи — шрифт Noto Color Emoji внутри проекта, поэтому одинаковы на любом компьютере.
